# Business Problem and Project Objective

## Project Title

Predicting House Prices Using Machine Learning

## Business Problem

House prices can be very different, even when houses are in the same area. Some houses are bigger, newer, or in better condition than others. This makes it hard for sellers to decide how much to ask for their homes.

I want to see if I can use house information to make price estimates instead of just guessing.

## Stakeholders

This project is mainly for home sellers and real estate agents who want some extra information when deciding on a house price.

## Project Question

Can I use machine learning to predict house prices based on things like house size, quality, and age?

## Project Objective

My goal is to try different regression models and compare their results to see which one predicts house prices better.

I also want to find out which house features are important and why some houses are harder to predict than others.

## Business Value

I think this project could help sellers and real estate agents get a better idea of how much a house might be worth.

They could use the predicted price as a reference when deciding on a listing price instead of relying only on guesses.

Of course, the model would not replace a real estate agent or a professional appraisal.

## Dataset

I am using the House Prices - Advanced Regression Techniques dataset from Kaggle.

The data comes from Ames, Iowa, and includes information such as house size, overall quality, year built, garage size, and sale price.

Dataset: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/overview

## Project Limitations

One limitation is that the data comes from Ames, Iowa, so the model might not work as well for houses in other cities.

I also noticed that some unusual houses are much harder to predict. For example, one large house in my dataset sold for only $160,000, but my first model predicted a price over $2 million.

This showed me that even when a model performs well overall, it can still make big mistakes on certain houses.
