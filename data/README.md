# Dataset - House Prices

## Data Source

Kaggle: House Prices - Advanced Regression Techniques

https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

This project uses the Ames, Iowa housing dataset for academic, non-commercial purposes.

## Download Instructions

1. Open the Kaggle dataset link above.
2. Sign in to your Kaggle account.
3. Accept the competition rules if prompted.
4. Click Download All.
5. Extract the downloaded ZIP file.
6. Copy the following files into this data folder:
   - train.csv
   - test.csv
   - sample_submission.csv

## Dataset Description

The training dataset contains 1,460 houses and 81 columns.

The target variable is SalePrice, which represents the final sale price of each house.

The dataset includes information about house size, overall quality, neighborhood, construction year, and other property characteristics.

## Data Usage

The competition data is intended for competition and academic, non-commercial use.

The original CSV files are not included in this public repository. Users must download them from Kaggle.
